特装ガチャ 2号機（PWA版）

追加したもの
1. 「引け！」のフレームで自動停止。
   画面の矢印に沿って上→下へ指を引くと演出が再開します。
2. 引く前のガチャ画面を動画ループに変更しました。
3. iPhone / iPad向け PWA（ホーム画面アプリ風）設定を追加しました。
4. 一度読み込んだ後にオフラインでも使いやすいようキャッシュ対応しました。

PCで試す
- index.html をブラウザで開くだけで基本動作を確認できます。

iPhone / iPadでホーム画面に置く
- PWAとしてホーム画面追加するには、このフォルダをHTTPSのWebサーバーに置く必要があります。
- SafariでそのURLを開き、共有 →「ホーム画面に追加」。
- 追加後はアイコンから起動し、アプリ風の全画面表示になります。

補足
- iOSの「ホーム画面ウィジェット」そのもの（時計や天気のような枠内で直接操作）はWebページだけでは作れません。
  それを本当に作る場合は、次の段階でSwift / WidgetKitのiPhoneアプリ版にします。
